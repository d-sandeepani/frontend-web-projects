# Word Counter

## Overview

WordCount is a single-page tool that analyses text as you type.

## Purpose

Quickly checks length for essays, posts and captions.

## Features

- Live counts: words, characters, characters without spaces, sentences, estimated reading time
- Top keyword list with frequency
- Character-limit progress bars for X/Twitter, Instagram and LinkedIn with remaining/over-limit status
- Clear button

## Technologies

HTML, CSS, JavaScript. No frameworks or build step; one self-contained `index.html`.

## Responsive Design

Layout adapts with CSS media queries. Tested without horizontal scrolling at 360, 390, 768, 1024 and 1440px widths.

## UI/UX

One focused text area with results updating instantly; colour-coded limit bars.

## Known Limitations

Uses Google Fonts (needs internet for the intended typefaces; falls back otherwise). Sentence counting is a simple punctuation-based estimate.
