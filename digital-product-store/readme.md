# Digital Product Store

## Overview

The Digital Edit is a front-end storefront interface for a fictional digital-product shop.

## Purpose

Shows how a digital-product shop can present bestsellers, categories and trust information.

## Features

- Bestselling products: 90-Day Life Reset Planner, Ultimate Habit Tracker, Digital Wellness Journal and more (prices $10-$19)
- Shop-by-category cards: Planners, Wellness, Fitness, Productivity, Finance
- 'Customer favorites' and benefits sections (instant access, easy to use)
- Testimonials and five-question FAQ
- Contact form

## Technologies

HTML, CSS. No frameworks or build step; the project is one self-contained `index.html`.

## Responsive Design

Layout adapts with CSS media queries. Tested without horizontal scrolling at 360, 390, 768, 1024 and 1440px widths.

## UI/UX

Pastel product-card grid with clear pricing and benefit callouts.

## Known Limitations

**Prototype only.** There is no cart, checkout, payment or order processing. Products are not real and nothing can be purchased. Phone navigation shows only the 'Shop Now' button.
