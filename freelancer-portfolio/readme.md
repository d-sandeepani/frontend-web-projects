# Freelancer Portfolio

## Overview

A portfolio site template for a freelance web designer and HTML developer.

## Purpose

Helps potential clients understand services, see example work and get in touch.

## Features

- Services: Business, Landing Page, Portfolio, Digital Product, Fitness & Wellness websites and Redesigns
- Project showcase featuring sample client sites (Coffee House, FitForward, Serenity Yoga, Everly & Rose, Haven & Co., The Digital Edit)
- Five-step process and 'why clients choose me' sections
- FAQ and project inquiry form (including budget field)

## Technologies

HTML, CSS. No frameworks or build step; the project is one self-contained `index.html`.

## Responsive Design

Layout adapts with CSS media queries. Tested without horizontal scrolling at 360, 390, 768, 1024 and 1440px widths. A hero-image overflow at ~1024px was found in testing and fixed.

## UI/UX

Minimal grey/coral palette, offset image frame and clear service-to-process flow.

## Known Limitations

The brand name still reads **'YOUR NAME.'** and email is `your@email.com`; replace before sharing. Form is front-end only.
