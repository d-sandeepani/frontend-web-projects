## Honest notes

- Projects 01-08 contain no JavaScript. They are HTML and CSS only; FAQs use native `<details>` elements.

- The Digital Product Store is a prototype: no cart, checkout or payments.
- All business names, prices, emails and phone numbers are fictional placeholders.
