# Fitness Coach Landing Page

## Overview

FITFORWARD is a landing page for a fictional personal fitness coaching business.

## Purpose

Guides visitors from "what is this?" to choosing a program and starting.

## Features

- Hero with repeated 'Start Your Journey' calls to action
- Three programs: Start Strong, Build & Grow, Total Transformation
- Results/testimonials section
- Pricing: Basic $49, Pro $79, Premium $119 per month
- Four-question FAQ using native `<details>` elements
- Contact form with a goals field

## Technologies

HTML, CSS. No frameworks or build step; the project is one self-contained `index.html`.

## Responsive Design

Layout adapts with CSS media queries. Tested without horizontal scrolling at 360, 390, 768, 1024 and 1440px widths.

## UI/UX

Strong headings, high-contrast buttons and a clear top-to-bottom story (problem, programs, proof, price, action).

## Known Limitations

Form is front-end only. On phones the navigation links are shown in a wrapped row rather than a hamburger menu.
